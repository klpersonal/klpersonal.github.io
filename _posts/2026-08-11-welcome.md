This is an example blog post.

With Jekyll, each post is simply a Markdown file in the `_posts` folder.
The filename follows the format:

`YYYY-MM-DD-title.md`

You can write paragraphs, **bold text**, links, lists, equations through
supported Markdown extensions, and code snippets.

## Why I created this site

Use posts for research notes, project updates, conference reflections,
short essays, teaching material, or anything else you would like to publish.
